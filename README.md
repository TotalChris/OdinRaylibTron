# Tron Lightcycles in Odin + Raylib
Attempt at a lightcycle game in Odin using Raylib. 


# Setup
- Install Odin using the [installation instructions](https://odin-lang.org/docs/install/)
- Using Git Bash (Windows) or your Unix-based terminal (MacOS, Linux), run `scripts/setup.sh`


# Run
- Use the default build and run scripts configured in the `.vscode` folder (See "VSCode Tasks")

OR

- Run `odin build` or `odin run` commands with the root folder as your build target


# VSCode Tasks
### Build Odin Project
Builds the project and debug symbols to `bin/debug/`
### Debug Odin Project
Runs the build task and uses the c++ extension to debug with the created symbols
